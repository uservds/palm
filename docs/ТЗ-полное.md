# ТЗ-полное: PalmAI (Палмис AI)

Обновлено: 2026-10-23
Статус: финальная версия для реализации в Replit (Next.js + Express)

## Решения, зафиксированные финально (2026-10-23)
1. **Цена совместимости**: 599 ₽ разово — подтверждено.
2. **Натальные карты**: связка Swiss Ephemeris (реальный астрономический расчёт натальной карты) + Gemini (генерация читаемого текста на основе расчёта) — не «или», а именно связка: Ephemeris считает точные данные, Gemini превращает их в литературный текст отчёта.
3. **История чата**: сохраняется в БД только для премиум-подписчиков; для бесплатных пользователей — НЕ сохраняется.
4. **Язык**: только RU (регион — только Россия), переключатель валют убран.
5. **Каналы доставки ежедневного гороскопа (2026-10-24)**: сайт + мессенджер (Telegram или MAX, на выбор пользователя) + email. MAX добавлен как альтернативный канал наравне с Telegram — не замена, а выбор пользователя.

## Регион и позиционирование
- Только Россия. Все цены в ₽, международной локализации нет.
- Ключевой месседж: «доступнее и быстрее», НЕ «дешевле». Слово «дешевле» исключено из всех текстов.

**Правила цвета:**
- `primary` (indigo) — только CTA-кнопки.
- `accent` (cyan) — только слой «ИИ/сканер»: линии, луч, статусы процесса. Не использовать как цвет текста на светлом фоне (контраст ниже AA).
- `brick` — точечно: индикатор «Линия сердца», раздел «Дата свадьбы». Не смешивать с accent в одном компоненте.
- `neutral.badge` — бейджи в Hero, не конкурируют весом с CTA.
- Состояния кнопок: default / hover / focus / disabled / loading — обязательны для кнопок запуска сканирования.

**Компоненты**: shadcn/ui (Button, Card, Input, Tabs, Badge, Switch, Dialog, Sheet, Avatar). Новые UI-библиотеки не добавлять.
**Стиль**: светлый, воздушный, тонкие бордеры, мягкие тени, скругления. Порядок вёрстки: desktop → tablet → mobile.

## Технологический стек

**Frontend**: Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui, Framer Motion, Lucide-react, MediaPipe Hands (детекция руки).
**Backend**: Node.js, Express, JavaScript (ESM), Prisma ORM, Zod, Multer, JWT, Google OAuth.
**БД**: PostgreSQL + Prisma.
**ИИ**: Google Gemini (основной) → OpenRouter (fallback) → Mock (тесты).
**Астрология**: Swiss Ephemeris (расчёт натальной карты) + Gemini (генерация текста отчёта на основе расчёта) — связка, не альтернатива.
**MediaPipe**: Modal.com (GPU-сервер) или в браузере.
**Платежи**: Stripe (только заглушка для разработки, НЕ для продакшена — в РФ не работает) + ЮKassa + CloudPayments (продакшен).
**Email**: Unisender.
**Мессенджеры**: Telegram Bot API + MAX Bot API — оба подключены как альтернативные каналы доставки (уведомления, ежедневный гороскоп); пользователь выбирает один или оба в настройках профиля.
**AI-картинки**: Midjourney / DALL-E (иллюстрации в PDF-отчёте).

## Чат с ИИ-хиромантом

- Плавающая кнопка справа внизу, цвет `#4F46E5`, бейдж «AI».
- Бесплатен для всех, без ограничения по числу сообщений.
- История сохраняется в БД только для премиум-подписчиков. Для бесплатных пользователей история НЕ сохраняется (обнуляется между сессиями).
- Общие вопросы о хиромантии — полный ответ. Персональные вопросы о конкретной ладони — переадресация на сканер.
- Запрещённые темы для фильтра: медицина (постановка диагнозов), финансы (конкретные инвестиционные советы), предсказания конкретных дат/событий с претензией на точность. Важно: это не запрещает ТЕМАТИЧЕСКОЕ обсуждение «что линия говорит о карьере/деньгах» в рамках хиромантии — запрет именно на выдачу реальных профессиональных рекомендаций.
