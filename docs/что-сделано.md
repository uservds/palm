# Что сделано — история разработки PalmAI

Обновлено: 2026-10-23

## Этап 1–9 (до 2026-10-16) — см. архив старого проекта

Проделана следующая работа (детали — в архиве `palms-clean-js`, который прикладывается отдельно):

1. Проанализирован исходный TypeScript-код, найдены проблемы (сложность, отсутствие структуры, auth, платежей).
2. Создана чистая JS-версия (`palms-clean-js`), backend переведён на Express + JavaScript (ESM).
3. Backend реализован: загрузка фото через multer, AI-провайдеры (mock/gemini/openrouter) с fallback-логикой, Zod-валидация, модерация, база знаний хиромантии, системный промпт.
4. Frontend реализован на Vite + React + TypeScript + Tailwind: состояния idle → preview → analyzing → result/error, превью 3 сек с анимацией сканирования.
5. Исправлены проблемы кодировки (mojibake CP866/CP1251 → UTF-8) и CORS между frontend/backend.
6. MVP протестирован: backend (порт 3001, mock-режим) + frontend (порт 5174) работают вместе, загрузка фото → отчёт с архетипом работает.
7. Составлено первое ТЗ для UI-прототипа (11 страниц), определена дизайн-система, 4 типа совместимости, структура тарифов, функциональность чата.
8. Приняты решения по стеку: Replit, Next.js App Router, Express+JS, PostgreSQL+Prisma, Modal.com для MediaPipe, ЮKassa/CloudPayments для платежей, Unisender, Telegram-бот.

## Этап 10 (2026-10-16 → 2026-10-23) — доработка ТЗ и маркетинговый аудит

Параллельно с технической частью проведена отдельная работа над структурой, текстами и маркетинговой логикой сайта:

1. **Маркетинговый аудит** исходной структуры и цветовой палитры — проверена контрастность, логика CTA, иерархия блоков.
2. **Проверена и доработана структура всех вкладок** («Возможности», «Тарифы», «Как это работает») — устранены логические нестыковки (дублирование иконки «Дом» и логотипа, порядок email-гейта в FreeReport, несогласованность цен между разделами).
3. **Переписаны все заголовки, подзаголовки, тексты кнопок** под нишу (хиромантия + ИИ) с учётом эмоционального позиционирования.
4. **Проработана логика FreeReport**: тизер-блоки с открытой петлёй вместо полного блюра, CTA переформулирован на вызов интереса, а не голую цену.
5. **Разработана преамбула бесплатного отчёта**: персонализация по имени, архетип, структура «находки → тень → интрига».
6. **Определена модель чата**: всегда бесплатен, без лимита сообщений, ограничение по глубине (не по количеству), фильтр тем.
7. **Решён вопрос позиционирования**: продукт — «доступнее и быстрее», не «дешевле»; регион — только Россия, валюта только ₽, переключатель валют убран.
8. **Финализирована тарифная сетка**: 399 ₽ разовый индивидуальный разбор, 590 ₽/мес подписка (единый тариф). Цена совместимости — открытый вопрос (599 vs 399 ₽).
9. **Сверены и устранены конфликты** между этим ТЗ и ранее принятыми техническими решениями (ЭТАП 1–9): история чата, архив разборов, язык сайта, платформа генерации UI.
